# Pillar 7: Interactive Calculators, Scorecards & Templates

This document contains ready-to-use worksheets, evaluation scorecards, profitability calculators, and communication templates for executing e-commerce product validation.

## 1. The 100-Point Product Opportunity Scorecard

Use this scorecard to evaluate every candidate product before committing capital or sourcing samples.

| Category | Evaluation Question | Score (0 - Max) | Max Pts |
| :--- | :--- | :--- | :--- |
| **Economics (25 pts)** | Can it retail for $\ge 4\times$ Landed COGS? (Gross Margin $\ge 75\%$) | | 10 |
| | Is the retail price in the sweet spot ($\$40-\$120$ US / ₹999–₹2,499 IN)? | | 10 |
| | Are payment and platform fees under $5\%$ total? | | 5 |
| **Demand & Hook (20 pts)** | Does it solve a severe pain point or trigger intense passion? | | 10 |
| | Can its core benefit be demonstrated visually in $< 3$ seconds? | | 10 |
| **Logistics (15 pts)** | Packaged weight $< 500\text{g}$ and compact shoe-box volume? | | 8 |
| | Non-fragile, non-perishable, and free from loose batteries / Hazmat? | | 7 |
| **Moat & Differentiator (15 pts)**| Can you fix a major flaw from competitor 3-star reviews? | | 8 |
| | Can you bundle a low-cost high-value accessory to stand out? | | 7 |
| **Sourcing Depth (10 pts)**| Are there $\ge 3$ verified factories producing this in an industrial hub? | | 5 |
| | Are initial trial batch MOQs $\le 200$ units? | | 5 |
| **Risk Profile (10 pts)** | Are there minimal sizing variations (one-size-fits-all)? | | 5 |
| | Is the expected return rate under $4\%$? | | 5 |
| **Expansion Potential (5 pts)**| Is there a clear path for consumable refills or complementary upsells? | | 5 |
| **TOTAL SCORE** | **Sum of all categories** | | **100** |

### Decision Thresholds:
* **80 – 100 Points**: **STRONG BUY / TEST IMMEDIATELY** (Tier 1 Priority).
* **65 – 79 Points**: **MARGINAL** (Needs bundle restructuring or margin renegotiation before testing).
* **< 65 Points**: **REJECT** (Kill and move to the next candidate).

## 2. Unit Economics & Profitability Calculator

### A. US Market Worked Example: Ergonomic Cold Gel Foot Massager

```
RETAIL SELLING PRICE (MSRP):                              $49.99   (100.0%)

EXPENSES & DEDUCTIONS:
├── Base Unit Factory Cost (Shenzhen/Yiwu):     $4.20
├── Custom Packaging Box + Insert Card:         $0.80
├── Air Cargo DDP Shipping (350g @ $6.50/kg):   $2.28
│   └── TOTAL LANDED COGS:                                -$7.28   ( 14.6%)
│
├── Customer Acquisition Cost (Blended CAC):             -$16.00   ( 32.0%) [Target ROAS: 3.1x]
├── 3PL Warehouse Pick, Pack & Local Postage:             -$6.50   ( 13.0%)
├── Payment Processing (Stripe 2.9% + $0.30):             -$1.75   (  3.5%)
├── Shopify Platform & App Fees (est. 2%):                -$1.00   (  2.0%)
└── Return Provision (4% Return Rate x $12 loss):         -$0.48   (  1.0%)
──────────────────────────────────────────────────────────────────────────
TOTAL EXPENSES:                                          -$33.01   ( 66.0%)

NET PROFIT PER UNIT (PRE-TAX):                            $16.98   ( 34.0%)
GROSS MARGIN:                                             $42.71   ( 85.4%)
```

## 3. Sourcing Request for Proposal (RFP) Templates

### Template 1: English Factory RFP (for Alibaba / Global Sourcing)

```text
Subject: RFQ: [Product Name] - Custom OEM Inquiry - [Your Brand Name]

Dear [Supplier Name / Sales Team],

My name is [Your Name], Head of Procurement at [Your Brand Name]. We are an e-commerce brand based in [Your Country], specializing in [Category Name].

We are expanding our product line and are interested in sourcing your [Product Model/Name]. Please provide an official quotation based on the following specifications:

1. PRICING TIERS (FOB & DDP [Your City/Port]):
   - Sample unit price
   - Tier 1: 200 units (with custom logo on product)
   - Tier 2: 500 units (with custom logo + custom packaging box)
   - Tier 3: 1,000 units
   - Tier 4: 3,000 units

2. PRODUCT & PACKAGING SPECIFICATIONS:
   - Material: [e.g., Anodized Aluminum / Food-grade Silicone]
   - Color: [e.g., Matte Black / Custom Pantone]
   - Unit Weight and Dimensions (packed in box)
   - Master Carton Dimensions and Gross Weight (units per carton)

3. PRODUCTION & SAMPLING:
   - Sample lead time and sample cost via DHL/FedEx to [Your Postal Code, Country]
   - Mass production lead time for 500 units upon deposit

4. COMPLIANCE:
   - Please attach existing certification test reports (e.g., CE, RoHS, FCC, FDA).

We look forward to establishing a long-term manufacturing partnership.

Best regards,

[Your Name]
Procurement & Sourcing Lead
[Your Brand Name]
[WhatsApp / WeChat ID]
```
